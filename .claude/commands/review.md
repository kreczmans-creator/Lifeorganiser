Follow the **Weekly review flow** in CLAUDE.md. Get the ISO week with
`date +%G-W%V`. Create the review note from `_templates/Weekly Review.md`
if it doesn't exist.

Walk the user through it **conversationally, one section at a time** — ask,
listen, write their answers into the note, then move on. Pre-fill what you
can compute yourself (habit completion from the week's daily notes, project
movement from logs) so they only supply the human parts.

Finish by: updating each project's status emoji, archiving anything declared
done, rebuilding the Command Center, and reading back next week's One Thing.
