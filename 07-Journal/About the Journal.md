# 📓 About the Journal

One note per day, named `YYYY-MM-DD.md`, created each morning by `/daily`.
Weekly reviews live here too, named `YYYY-Www Review.md`.

The daily note holds: today's one thing, tasks (with carry-over from
yesterday), habit checkboxes, and an evening reflection. Habit checkboxes are
what powers the streaks on the [[Command Center]].
